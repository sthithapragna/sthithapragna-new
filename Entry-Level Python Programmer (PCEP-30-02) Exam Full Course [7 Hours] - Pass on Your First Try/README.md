## How to use these

This exam asks you to read code and say what it prints, so the slides are worth more
with a Python prompt open beside them. Type the examples out rather than reading
them — the questions that catch people are the ones where the answer is an error,
not a value.

Module 22, Spot the Error, is the one to repeat. Every practice paper draws on it.
The four papers are 30 questions each at roughly 80 seconds a question, matching the
real exam, so sit them under timed conditions once all 25 modules are done.

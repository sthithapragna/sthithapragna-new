## How to use these

Work through a module video, then keep its PDF open for review. The three practice
exams are best saved until you have finished all 41 modules — sit each one under
timed conditions before checking answers.

Coming from MLA-C01, start with module 40, which sets out what is different. Module 38
is worth reading early too: several services on this exam are in maintenance mode, and
knowing what replaced them is not the same as knowing what to answer.

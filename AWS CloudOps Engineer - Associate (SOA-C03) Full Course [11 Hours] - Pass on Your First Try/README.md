## How to use these

Work through a module video, then keep its PDF open for review. The four practice
exams are best saved until you have finished all 36 modules — sit each one under
timed conditions before checking answers.

If you studied for the old SysOps Administrator version of this exam, read module 33
first. It covers what changed and what AWS renamed, which is the difference between
material that is merely dated and material that is now wrong.

## How to use these

Work through a module video, then keep its PDF open for review. The four practice
exams are best saved until you have finished all 39 modules — sit each one under
timed conditions before checking answers.

Coming from the previous version of the exam, start with module 39, which covers
what changed from SCS-C02.

## How to use these

The parts build on each other and later modules assume the earlier ones, so the first
pass is best done in order. Part 8 is where you find out whether it stuck: the
diagnostics and the unsolved set are deliberately handed over without telling you
which technique they need.

Each deck works as a reference afterwards — the assertions and the engine differences
are on their own slides, which is what you will want to look up again.

## How to use these

Follow the module numbers the first time through. The order is deliberate —
how Claude generates comes before the API, the API before application design,
and tools before agents — so jumping straight to a domain means meeting ideas
that an earlier module was supposed to have introduced.

Domain 2 is a third of the exam on its own and is spread across ten modules.
Domains 3 and 4 together are under 6%, so modules 27 and 30 need far less of
your time than their position in the course suggests.

Module 32 dates every change from July to October 2026 that touches the exam,
with the exam-safe reading for each. On a certification this new, that gap
between what shipped and what the guide says is worth knowing before you sit it.

The three practice papers run to a full 53-question sitting between them —
save them until all 34 modules are done and sit each under timed conditions.

## How to use these

Module 01 sets out how a release actually flows through AWS end to end. It is worth
watching before the domain modules even though it is not tied to one — most of this
exam's scenarios are a question about one stage of that flow.

Work through a module video, then keep its PDF open for review. The four practice
exams are best saved until you have finished all 31 modules — sit each one under
timed conditions before checking answers.

Module 30 covers what has changed since the exam guide was published, which matters
on a professional-level exam where a lot of the tooling has been renamed or replaced.
